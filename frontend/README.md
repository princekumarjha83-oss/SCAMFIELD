# ScamShield AI — Client Frontend 🛡️

Interactive cybersecurity dashboard for ScamShield AI built with React 19, Vite, and CSS 3D holographic transforms.

- **🌐 Live Production Application**: [https://scamfield-9pin.vercel.app](https://scamfield-9pin.vercel.app)
- **⚡ Backend Threat Intelligence API**: [https://scamfield.onrender.com/api/v1/health](https://scamfield.onrender.com/api/v1/health)

## Features
- **3D CyberShield Hero**: Interactive perspective tilt and rotating frequency rings.
- **4 Threat Scanning Workspaces**:
  - Message & SMS Scanner
  - URL Phishing Lexical Scanner
  - Screenshot Image OCR Scanner
  - Email Spoofing & Header Inspector
- **Audit History & Modality Filtering**: Filter records by `URL`, `MESSAGE`, `SCREENSHOT`, and `EMAIL`.
- **Live Threat Telemetry & Analytics**: Visualized risk distributions and top threat indicators.
